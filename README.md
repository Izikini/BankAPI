# 💰 BankAPI

**PHP** web application simulating a simple banking system with API functionality.

---

## 📁 Project Structure

```bash
BankAPI/
├── bankAPI/                            # Main Project Folder
│   ├── index.php                       # Main page
│   ├── login.php / register.php        # Authentication
│   ├── dashboard.php                   # User dashboard
│   ├── transfer.php                    # Money transfer
│   ├── api/                            # API endpoints (if present)
│   ├── assets/                         # CSS, JS, images
│   ├── includes/                       # Configuration & helpers
│   └── ... (other PHP files)
│
├── phpDocumentor.phar                  # Documentation generator
├── .gitignore
├── .gitattributes
└── README.md
```
## ✨ Features
* Money transfers between accounts
* Banking operations simulation
* RESTful API elements (backend)

## 🛠 Technologies

* PHP (Backend)
* MySQL / Database (likely)
* Web-based application


## ▶️ How to Run
1. Clone the repository
```
git clone https://github.com/Izikini/BankAPI.git
cd BankAPI
```
2. Setup & Run

**_NOTE:_** Place the bankAPI folder in your local server directory:
XAMPP → htdocs/bankAPI

* Start Apache and MySQL in XAMPP
* Import database **bankapi.sql**
* Update database configuration in the project files.

Educational project for practicing web development with PHP:
